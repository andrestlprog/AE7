# Módulo 2 - Aprendizaje esperado N° 7

Esta evaluación permite conocer mejor cómo funciona GIT y su eficiencia en el control de versiones.

# Funcionalidades
- Creación de un repositorio local en GIT
- Subida del repositorio a GitHub
- Implementación de una barra de navegación básica en HTML
- Uso de ramas para nuevas funcionalidades

## Ramas utilizadas
- main: rama principal del proyecto
- feature/navbar: rama utilizada para agregar la barra de navegación

## Tecnologías 
- HTML
- GIT
- GITHUB
